Method. 1-year interest = deposit × APY (APY is the effective annual yield, which already reflects compounding, assuming the rate stays constant and interest remains in the account). 5-year interest = deposit × ((1 + APY)5 − 1). Above the FDIC limit — what happens to the return

The FDIC insures $250,000 per depositor, per bank, per ownership category (fdic.gov). Deposits above that at a single bank are exposed in a failure:

Total deposit (one bank, one ownership category) FDIC-insured Uninsured
$250,000$250,000$0
$500,000$250,000$250,000
$1,000,000$250,000$750,000
  • Strategy for larger savings: split across separately chartered FDIC banks (the limit applies at each bank), use different ownership categories (joint accounts add $250,000 per co-owner; certain retirement accounts are separately insured; revocable trusts add $250,000 per owner per unique beneficiary, up to 5), or use a program like SoFi’s Insured Deposit Program (advertised up to $3M through participating banks).
