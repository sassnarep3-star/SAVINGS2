## Fourth artifact: Session B research site (`docs/`)

A third parallel session (`arena/24e1eb4e-savings2`, "Session B") independently verified
the same core banks from official sources — including several values the other sessions
initially left blank (Chase 0.01% via the `rdin1.pdf` rate sheet, Bank of America 0.04%
via the NY Tri-State rate sheet, Capital One 3.20% via the application rate table,
Synchrony 3.55% via `synchrony.com/banking/products/hys-core`) and, uniquely, the
**Capital One BONUS1500 savings bonus** (up to $1,500; verified at
<https://www.capitalone.com/bank/bonus1500/>) and the **PNC Virtual Wallet $100/$400
bonus** (valid 2026-09-01 – 2027-01-07; verified at
<https://www.pnc.com/en/personal-banking/banking/checking/bonus-offer.html>).

Its hand-built 11-page dashboard is retained in this repository at **`docs/`** (open
`docs/index.html`), alongside its reproducible projection script
(`tools/returns_calc.py`) and site checker (`tools/site_check.py`). The two
materially-unique verified offers were merged into the canonical datasets
(`data/promotions_and_rules.json`) and regenerated into the live Pages site during the
final integration; all of Session B's values agreed with the canonical datasets where
they overlap.
